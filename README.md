# Pet Shelter Telegram Bot

## Описание проекта
Telegram-бот для приюта животных в Астане, созданный для автоматизации консультаций потенциальных хозяев и сбора ежедневных отчетов о адаптации животных.

## Основной функционал
- Консультация новых пользователей о приюте
- Помощь потенциальным хозяевам в процессе усыновления
- Прием и обработка ежедневных отчетов о питомцах
- Связь с волонтерами приюта

## Технологии
- Java 17
- Spring Boot
- Spring Data JPA
- Telegram Bot API
- PostgreSQL
- Maven

## Участники проекта
- Разработчики: reapersans28, R2echka
- Волонтеры приюта (администраторы бота)

## База данных
Проект использует PostgreSQL для хранения:
- Информации о пользователях и приютах
- Данных о животных и процессе усыновления
- Ежедневных отчетов и рекомендаций

## API для волонтеров
Реализованы REST endpoints для:
- Получения необработанных отчетов
- Отметки о просмотре отчетов
- Выгрузки отчетов по ID
- Отправки уведомлений о качестве отчетов

## Запуск проекта
1. Клонировать репозиторий
2. Настроить подключение к БД в `application.properties`
3. Указать токен бота в конфигурации
4. Запустить приложение: `mvn spring-boot:run`
